# Лабораторная работа №3. Очередь задач: итераторы и генераторы
### Выполнила: Китаева Дарья М8О-102БВ-25

## Цель работы
Научиться реализовывать пользовательские коллекции и использовать генераторы для ленивой обработки задач.

## Постановка задачи
Необходимо разработать очередь задач `TaskQueue`, которая:
- поддерживает итерацию;
- допускает повторный обход элементов;
- выполняет ленивую фильтрацию задач;
- позволяет выполнять потоковую обработку задач;
- корректно работает со стандартными конструкциями Python.

## Что реализовано
В проекте реализованы:
- класс `Task` для хранения информации о задаче;
- класс `TaskQueue` для хранения набора задач;
- метод `__iter__()` для поддержки цикла `for`;
- метод `filter()` для ленивой фильтрации по статусу и приоритету;
- метод `process()` для ленивой обработки задач;
- демонстрационная программа в `main.py`;
- тесты в `tests/test_task_queue.py`.

### Класс `TaskQueue`
Пользовательская коллекция задач.

Поддерживает:
- добавление задач методом `add_task()`;
- итерацию по объекту;
- повторный обход очереди;
- ленивую фильтрацию через `yield`;
- ленивую обработку задач через `yield`.

## Пример работы программы
После запуска выводятся:
- все задачи;
- задачи со статусом `new`;
- задачи с выбранным приоритетом;
- результат ленивой обработки задач.
