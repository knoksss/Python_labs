## Описание проекта
Менеджер задач - это консольное приложение для управления и асинхронной обработки задач. Программа позволяет получать задачи из различных источников, управлять очередью задач и выполнять их асинхронно с использованием нескольких работников.

## Основные возможности
1. Получение задач из трёх типов источников:
   - из файла (чтение задач из текстового файла);
   - через API-заглушку;
   - с помощью генератора случайных задач.

2. Управление очередью задач:
   - фильтрация задач по статусу;
   - фильтрация задач по приоритету;
   - ленивая обработка задач.

3. Асинхронное выполнение задач:
   - параллельная обработка несколькими работниками;
   - расширяемая система обработчиков;
   - сбор статистики выполнения.

4. Валидация данных:
   - проверка корректности приоритета *(от 1 до 5)*;
   - проверка статуса задачи *(new, in_progress, done)*;
   - проверка описания задачи *(не может быть пустым)*.

## Технологии
- *Python 3.11+*
- *asyncio* - для асинхронного выполнения задач;
- *pytest* - для тестирования;
- *pytest-asyncio* - для тестирования асинхронного кода;
- *pytest-cov* - для проверки покрытия тестами;
- *typing.Protocol* - для определения контрактов.

## Ключевые компоненты
### Класс Task
Представляет задачу с атрибутами:
- *id* - уникальный идентификатор;
- *description* - описание задачи;
- *priority* - приоритет (1-5);
- *status* - статус (new, in_progress, done);
- *creation_time* - время создания.

### Дескрипторы
**PriorityDescriptor:**
- валидация приоритета (целое число, диапазон 1-5);

**StatusDescriptor:**
- валидация статуса (только new, in_progress, done);
- автоматическое приведение к нижнему регистру;

**DescriptionDescriptor:**
- валидация описания (строка, не пустая, не из пробелов).

### Очередь задач
Класс ```TaskQueue``` для хранения и управления набором задач.
**Методы:**
- *add_task(task)* - добавление задачи в очередь;
- *iter()* - поддержка итерации (возвращает генератор);
- *len()* - возвращает количество задач;
- *filter(status, priority)* - ленивая фильтрация задач (возвращает генератор);
- *process(func, tasks)* - ленивая обработка задач (возвращает генератор).
**Особенности:**
- поддерживает повторный обход элементов;
- фильтрация и обработка работают лениво (через yield);
- совместима со стандартными конструкциями Python (len, sum, list).

### Источники задач
**ApiSource:**
- возвращает фиксированный набор задач (заглушка API);
- используется для демонстрации работы с внешним API.
**FileSource:**
- читает задачи из текстового файла;
- каждая строка файла становится отдельной задачей;
- приоритет задаётся по умолчанию (3).
**GeneratorSource:**
- генерирует 5 случайных задач;
- случайные id от 1 до 100;
- случайные описания из набора ['A', 'B', 'C'];
- случайные приоритеты от 1 до 5.

### Асинхронный исполнитель
**Класс AsyncTaskExecutor:**
- асинхронная очередь задач (asyncio.Queue);
- несколько работников для параллельной обработки;
- регистрация обработчиков через register_handler();
- сбор статистики выполнения.
**Протокол TaskHandler:**
- *can_handle(task) -> bool* - проверка возможности обработки;
- *handle(task) -> None* - выполнение задачи.
**Обработчики:**
- *PrintHandler* - обрабатывает любые задачи, выводит информацию;
- *PriorityHandler* - обрабатывает только задачи с приоритетом 4-5.
- автоматический запуск и остановка исполнителя;
- корректное управление ресурсами.

## Пример работы программы
При запуске программы пользователь видит меню с командами. Основные сценарии использования:
- Просмотр задач из разных источников *(команды 1-3)*;
- Проверка, какие классы соответствуют протоколу TaskSource *(команда 4)*;
- Демонстрация работы очереди: фильтрация по статусу, преобразование описаний *(команда 5)*;
